# Getting help

- **Questions and ideas:** open a [feature request](https://github.com/Division4Studios/multi-agent-local-team/issues/new?template=feature_request.yml) or start a GitHub Discussion (once enabled).
- **Bugs:** open a [bug report](https://github.com/Division4Studios/multi-agent-local-team/issues/new?template=bug_report.yml) with reproduction steps, your OS, your VS Code version and your MALT version.
- **Security issues:** never in public. See [SECURITY.md](SECURITY.md).

MALT is maintained by volunteers. We read everything but can't promise response times.
